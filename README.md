# Sales Performance Dashboard

![Dashboard preview](dashboard-preview.png)

An interactive Power BI dashboard that analyses sales performance across time, products, regions and categories.
Built as Project 1 of my Data Analysis virtual internship at Syntecxhub.

## What it does
- Cleans raw sales data in Power Query (data types, nulls, duplicate order IDs)
- Shows monthly, quarterly and yearly sales trends with drill-down
- Ranks the top 5 and lowest 5 products by revenue
- Compares sales by region and by category
- Tracks KPIs: total revenue, total profit, profit margin, growth rate and average order value
- Filters everything by year, region and category

## Dataset
Sample sales data, 1,200 orders from January 2024 to November 2026, with 5 regions, 4 categories and 20 products.

## Growth rate note
2026 data ends in mid-November, so growth compares the same dates in the previous year. This avoids showing a false decline.

## Tools
Power BI, Power Query, DAX
